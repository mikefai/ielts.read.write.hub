# IELTS Academic: Structure and Method Guide (research brief, Oct 2026)

## 1. Verified structure
Reading source: ielts.org Academic Reading format page. Other figures: British Council and IDP summaries. I found no source showing 2026 changes to the Academic format. Re-check ielts.org before launch.

| Skill | Time | Questions / tasks | Notes |
|---|---|---|---|
| Listening | ~30 min + 10 min transfer (paper) | 40 Qs, 4 recordings | Same for Academic and General Training. Recording 4 is an academic lecture. |
| Reading | 60 min, no transfer time | 40 Qs, 3 passages, 2,150-2,750 words total | Non-specialist texts from books, journals, magazines, newspapers. At least one has a detailed argument. |
| Writing | 60 min | Task 1 (150+ words, ~20 min), Task 2 (250+ words, ~40 min) | Task 2 carries twice the weight of Task 1. |
| Speaking | 11-14 min | 3 parts | Same for Academic and General Training. May be on a different day. |

Reading has 11 question types: multiple choice; True/False/Not Given; Yes/No/Not Given; matching information; matching headings; matching features; matching sentence endings; sentence completion; summary/note/table/flow-chart completion; diagram labelling; short answer.

Writing is marked on 4 equal criteria (descriptors updated May 2023): Task Achievement (Task 1) or Task Response (Task 2); Coherence and Cohesion; Lexical Resource; Grammatical Range and Accuracy.

## 3. Reading: how to find answers

### Universal 5-step method
1. **Skim the passage first (60-90 sec).** Note each paragraph's topic and label paragraphs A, B, C.
2. **Underline keywords in the question.** Names, numbers, dates and unusual nouns stay in the text. Common words get paraphrased.
3. **Predict the paraphrase.** The text rarely repeats the question's words ("rise" = "climb", "cause" = "stem from").
4. **Locate, then read closely.** Find the keyword or its paraphrase, then read the sentence before and after.
5. **Confirm, don't assume.** If you can't point to a line that proves it, you haven't found the answer.

About 20 minutes per passage. Completion, T/F/NG and short-answer questions usually follow passage order. Matching headings and matching information do not.

### Method per question type
| Type | How to find the answer |
|---|---|
| **True / False / Not Given** | Find the sentence on the statement's topic. True = same meaning in other words. False = opposite meaning. Not Given = topic appears but the text never confirms or denies the specific claim. Watch qualifiers: all, only, always, never, mainly, may. |
| **Yes / No / Not Given** | Same logic, applied to the writer's opinion or claim, not facts. Opinion signals: argue, suggest, fail to, it is clear that. |
| **Matching headings** | Read each paragraph's first and last sentence, where the main idea usually sits. Choose the heading that covers the whole paragraph, not one detail. Do easy ones first and cross out used headings. |
| **Matching information** | The question is a detail ("an example of X"). Scan paragraphs for that detail by keywords and paraphrase. A letter may be used more than once. |
| **Matching features** | List the names, theories or dates from the options, find each in the text, and match the claim made about it. |
| **Matching sentence endings** | Predict the grammar and meaning of the ending from the stem, then find the stem's topic in the text. Several endings are distractors. |
| **Multiple choice** | Locate the topic, then test each option against the text. Drop options that are too extreme, only partly true, or true but off-question. |
| **Sentence / summary / note / table / flow-chart completion** | Check the word limit. Decide what part of speech is missing. Copy the exact words, with no changes. For summaries, find where that section begins in the text. |
| **Diagram labelling** | Find the passage describing the process or object and follow its order along the diagram. |
| **Short answer** | The question word (who, what, when) tells you the answer type. Copy exact words within the limit. |

### Common traps
- Picking an answer because a word matches, when the meaning differs.
- Using outside knowledge. Only the passage counts.
- Exceeding the word limit or changing the word form.
- Leaving blanks. Wrong answers lose no marks.

## 4. Writing Task 1 (Academic): sentence-by-sentence blueprint
Target: 150+ words (aim for 170-190), about 20 minutes. Four paragraphs, 8-11 sentences.

| Para | Sentence | Role | Score value |
|---|---|---|---|
| Intro | 1 | **Paraphrase the prompt.** What the visual shows, where, when. | Task Achievement. No opinions. |
| Overview | 2 | **Main trend or main feature.** The biggest change or difference. | Key requirement for Band 6+. A missing overview is the commonest cause of low scores. |
| | 3 | **Second key feature.** A contrast, a second trend or a stand-out figure. | Shows you can select main features. No numbers yet. |
| Body 1 | 4 | **Topic sentence.** Introduce the first group of data. | Coherence. |
| | 5 | **Key figures.** Exact data for the main item, with units. | Accuracy. |
| | 6 | **Comparison** using whereas, while, higher than. | Range of structures. |
| | 7 | **Trend detail** over time: rose steadily to, peaked at. | Vocabulary and tense control. |
| Body 2 | 8 | **Topic sentence.** Introduce the second group. | Coherence. |
| | 9 | **Key figures.** | Accuracy. |
| | 10 | **Comparison or link back to Body 1.** | Cohesion. |
| | 11 (optional) | **Closing detail.** One more notable point. | Completeness. No conclusion needed. |

Rules: describe, don't explain causes. Group data logically instead of item by item. Match tenses to the time frame. For processes use "stages" instead of "trends"; for maps use "changes".

## 5. Writing Task 2: sentence-by-sentence blueprint
Target: 250+ words (aim for 270-300), about 40 minutes. Four or five paragraphs, 14-18 sentences.

**Introduction (2-3 sentences)**
| Sentence | Role |
|---|---|
| 1 | **Background.** Paraphrase the topic neutrally. |
| 2 | **Thesis.** Answer the question directly (agree/disagree, both views plus your opinion, or the causes/solutions). Reuse the question's key terms. |
| 3 (optional) | **Outline.** What the essay will cover. |

**Body paragraph (4-5 sentences; 2 paragraphs, 3 for some questions)**
| Sentence | Role |
|---|---|
| 1 | **Topic sentence.** One main idea, linked to the thesis. |
| 2 | **Explanation.** Why or how the idea holds. |
| 3 | **Example.** Specific and believable (a country, a study, a common situation). |
| 4 | **Result or effect.** What the example proves or what follows. |
| 5 (optional) | **Link.** Tie back to the question or bridge to the next paragraph. |

**Conclusion (2 sentences)**
| Sentence | Role |
|---|---|
| 1 | **Summary.** Restate position and main reasons in new words. |
| 2 | **Final judgement.** A short closing thought. No new ideas. |

**Adjusting by question type**
- Opinion: Body 1 is your strongest reason; Body 2 is a second reason or a rebutted counter-argument.
- Discussion: Body 1 View A, Body 2 View B; opinion in intro and conclusion.
- Problem/solution or causes/solutions: Body 1 problems or causes, Body 2 solutions or effects, each solution matching a problem.
- Two-part question: one body paragraph per question.
- Advantages/disadvantages: one paragraph each, plus a judgement if asked.
